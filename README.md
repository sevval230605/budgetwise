# BudgetWise 💰

BudgetWise, kullanıcıların kişisel gelir ve giderlerini takip edebildiği web tabanlı bir bütçe yönetim uygulamasıdır.

## 🚀 Canlı Uygulama

https://budgetwise-coral.vercel.app

## ✨ Özellikler

- Kullanıcı kayıt ve giriş sistemi
- JWT tabanlı kimlik doğrulama
- Gelir ekleme ve listeleme
- Gider ekleme ve listeleme
- Kullanıcıya özel finansal veriler
- BCrypt ile güvenli şifreleme
- Responsive tasarım
- PWA desteği
- Mobil ve masaüstü cihazlarda kullanım

## 🛠️ Kullanılan Teknolojiler

### Backend
- Java
- Spring Boot
- Spring Security
- JWT
- JPA / Hibernate
- H2 Database

### Frontend
- React
- TypeScript
- Vite
- HTML
- CSS

### Deployment & Tools
- Git
- GitHub
- Vercel
- Render
- Maven
